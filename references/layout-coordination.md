# 图文与按钮的协同排版

参考培训卡的阅读顺序和模块关系，不复制品牌、蓝紫渐变、人物、粗体或水印。
本规范只管信息布局；preset、image-art-direction 中的字体/色板及显式用户风格保持不变。

## 选择整卡结构

- 通知/培训：轻量横幅 → 一句价值或关键时间 → 原生模块 → 对应行动。已有显式图片模式优先；三个及以上阶段/指标等复杂视觉关系保留信息图。
- 案例/数据：信息图回答一个核心关系，原生层保留可复制的关键事实、短解释和行动。不要在图片下再重复一整篇相同信息图。
- 多个并列主题：使用相同骨架（标题、短说明、必要图片、按钮）；不把不相关主题装进一段，也不强行把长段落并排。
- 图片、文字、按钮共享内容宽度和左边线。模块内约 4px、模块间约 16px 是默认节奏，不是用空白占满卡片。

## 图片与文字的接缝

横幅只放一个标题与最多两个短信息组；指标型横幅最多一个焦点指标。标题独占一行、指标标签和值共享下一行，不使用大标题左栏挤压标签右栏。长解释留原生层；首屏应能看到下一块原生信息。
信息图使用完整展示 fit_horizontal，不用居中裁切掩盖信息过长。不要给已有 Card 再嵌套一层海报边框。
透明底仍可用；按实际卡片底色检查。参考图只影响构图时，不能连带换成参考图的渐变、字体、Logo 或人物。

## 模块与行动

同一模块的标题、说明、图片和行动相邻；按钮文案应说明对象和动作。
自动归属只接受可唯一确定的原文标题区间；重名模块、重复 URL、被省略模块的链接不得猜归属。
总览、全部、回顾等全局行动留底部。没有真实 URL 或已实现回调，记录待补，不画假按钮。
默认保留一个主行动和最多一个次行动；不要为了模仿参考图而无依据增加入口。

可编辑 section 支持 actions（真实按钮列表）和 coordinated=true，编译为原生单栏容器。
并列的短模块或图文组合使用已有 columns DSL：两列 weight=1、flex_mode=stretch、列内 padding=0px、
vertical_spacing=4px、列间 horizontal_spacing=12px；移动端按顺序读，长文直接单列。
模块已有背景时不再嵌套层层色块。高级列布局需在目标飞书客户端验证，本地近似预览不代表真机验收。

## 执行和复核

scripts/layout_coordination.py 在新生成阶段记录版式选择和按钮归属证据；--resume 不重排已有人工编辑。
使用新图片模式必须重新生成、登记和上传，不能拿旧竖图硬塞横幅。
复核整卡，不只看单张图片：360px 和桌面宽度各看一次，检查图片是否截字、标题与正文间距、
模块与按钮归属、左右边线、重复内容及长按钮换行。不要为对齐而补造数字、删关键限定词或伪造已实测。
