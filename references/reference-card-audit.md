# 五张参考卡片逆向拆解

这份审计把用户提供的五张飞书卡片截图转成可执行的版式、图片和交互规则。它只吸收信息组织方式，不复制截图中的品牌、Logo、人物或具体文案。

## 一、逐张拆解

### 参考图 1：企业迁移案例

结构是：顶部标题和状态标签 → 横向案例封面 → 客户背景 → 三项核心指标 → 项目里程碑 → 三列项目亮点 → 三列迁移成果 → 领导寄语。

- 封面图用“相机/影像 × AI/协同”的单一关系表达迁移主题，标题由卡片文字承载，图片负责建立场景和情绪。
- 指标区域是短标签、数值和变化关系的横排，不用长段落解释指标。
- 里程碑先有原生文字摘要，下面再用三个等宽阶段卡把“准备 → 培训 → 切换”画成关系图。
- 项目亮点和迁移成果都用三列短标题 + 短解释；长句没有被压缩到图片里。
- 底部寄语独立成块，与业务事实分开，强调引用而不是装饰。

### 参考图 2：课程周历

结构是：品牌/状态头部 → 宽幅课程 Banner → 两个系列标签 → 两列课程模块 → 固定时间块 → 周一至周五课程行 → 每列一个主按钮 → 说明。

- Banner 使用“日历 + 火箭”表现“本周课程已就位”，图片不是课程详情表，而是课程状态和行动方向的视觉入口。
- 两列模块有严格相同的骨架：标题、说明、时间、周次列表、按钮；蓝紫颜色只用来区分系列。
- 时间和周次是信息主角，按钮的宽度、圆角、位置完全一致。
- 装饰元素很少，真正的信息密度来自对齐的行列和重复的模块结构。

### 参考图 3：培训通知

结构是：通知标题 → 豆包主题横幅 → 系列一的开课时间 + 预约按钮 → “你将看到”四项 → 福利提醒 → 系列二的时间 + 课程重点/收获 → 三个预约按钮。

- 首图很轻，留白多，承担品牌主题和课程气质，不抢后面的事实信息。
- 四项能力用 2×2 对齐卡片呈现，主问题词短而醒目，解释文字留在原生文字层。
- 福利提醒是独立的浅色高亮条，和课程事实分开，便于快速扫描。
- CTA 紧邻对应课程模块，用户不用回到卡片底部猜按钮作用。

### 参考图 4：企业培训周课表

结构是：标题/状态 → 宽幅“官方培训”封面 → 一句话价值 → 三个“认识/找到/会用”能力入口 → 课程模块 → 课程亮点与收获二栏 → 固定开课时间 → 2×2 日期按钮 → 回顾按钮。

- 封面右侧用一个人物和上升箭头表达“AI 工作伙伴”，左侧保留标题安全区；这是 Seedream 5.0 Pro 整图可以承担的关系。
- 三个能力入口是同宽短卡，使用统一词性和统一高度，不能把长文案塞进三栏。
- 课程事实采用“解释文字 + 日期按钮”的双层结构：原生文字解释价值，按钮承担具体入口。
- 主色蓝贯穿标题、时间和按钮，颜色是信息语义的一部分，不是随机装饰。

### 参考图 5：课程复盘/产品能力

结构是：复盘标题 → 宽幅产品场景 Banner → 一句话产品价值 + 全宽 CTA → 能力模块 → 左侧文字说明 + 右侧真实 UI 截图 → 每模块 CTA → 全宽回看 CTA。

- 顶部 AI 人物和多窗口界面是场景化封面，下面的真实截图才负责证明产品实际能力。
- 每个能力模块都形成“价值标题 → 事实列表 → 真实截图 → 查看路径按钮”的闭环。
- 真实截图不应该被生图模型重绘；截图中的 UI 文字属于证据，必须保留原像素。
- 大按钮用来总结一个明确的下一步，不用多个相似按钮稀释注意力。

## 二、五张图共同的结构骨架

```text
标题/状态
  ↓
横向功能性封面（Seedream 5.0 Pro 主题关系 + 少量来源锁定短标签）
  ↓
一句话价值或重点提醒
  ↓
原生事实模块（指标 / 能力 / 课程 / 时间轴）
  ↓
图片证据或文字-图片二栏（需要真实截图时优先真实图片）
  ↓
对应模块旁的原生按钮
  ↓
引用、回顾或一个总 CTA
```

### 可迁移的硬规则

1. **图片是信息模块，同时也是完整视觉交付物。** Seedream 5.0 Pro 可以把图片分工选中的标题、关键关系、时间线和寄语组织在一张完整 `hero.png` 中；Card 原生层另外保留完整、可编辑、可访问和可交互的结构。
2. **图片围绕一个主要信息任务组织。** 可以是主题状态、阶段关系、指标关系或 UI 证据；只把少量源锁定标签放入图片，通过层级、分区和留白形成一个清楚的阅读任务，不能变成无层级文字墙。
3. **Seedream 5.0 Pro 直接生成完整卡片。** 它负责对象、路径、场景、被选中的中文、日期、数字和引用的排版；按钮、真实 URL 和点击行为留在原生 Card，禁止先生成关系底图再用其他工具补字。
4. **最终图片必须有可读的功能文字。** 时间线图片直接显示被分配的各阶段日期和动作，quote 图片直接显示被选中的短寄语；完整寄语和细节同时保留在原生 Card，文字错误只能重新调用 Seedream 5.0 Pro，不能后处理。
5. **图片与原生文字要互补。** 图片快速回答“是什么、先看哪里、怎么流转”；原生文字回答“具体事实是什么”。二者不复制长段落，也不能互相矛盾。
6. **图片与按钮要邻近配对。** 图片可以通过信息关系把视线导向动作，但点击行为只放在飞书原生 `button + behaviors`；图片里禁止出现按钮、CTA 胶囊、假链接或按钮形控件。
7. **真实截图是证据。** Logo、照片、看板和 UI 截图使用 `real_image`，保留像素、来源、尺寸和 alt；AI 不得重绘准确界面。
8. **网格优先于装饰。** 默认单列；只有短标签、KPI 和两条课程路线使用 2～3 列。列宽、卡片高度、间距、圆角和按钮宽度必须统一。
9. **信息密度要有节奏。** 大标题短，解释分段，重点用浅色模块或高亮条；一个模块不同时承担标题、长正文、指标和 CTA。
10. **Emoji 是语义路标。** 保留原文 Emoji，默认可按原文语义补充少量路标，每个大模块最多一个；用户要求无 Emoji 时关闭，不能用 Emoji 填空。

## 三、当前执行标准

以下历史样例只作信息结构参考；实际图片模式、精简正文和 CTA 邻近规则以 [layout-coordination.md](./layout-coordination.md) 为准。保留当前 image-art-direction 的瑞士编辑风格，不因借鉴布局而复制品牌色、人物或水印。

轻量通知/培训可自动选择横幅，复杂关系使用 `seedream_5_pro_direct_full_card` 信息图，显式图片模式优先。Seedream 5.0 Pro 一次性生成当前模式的最终图片，仅写入 information_allocation.image.include；原生 Card 保留简短摘要、可复制的必要事实和真实按钮，完整原文留在 source.txt。`reference_card_banner` 仅为构图参考，不是第二阶段处理入口。

## 四、按内容选用的图片任务

以下是结构参考，不要求每张卡片全部出现。横幅仅一个焦点指标或最多两个短标签；三阶段及以上关系使用信息图。未提供的时间、寄语、按钮和图片素材不得补造。

| 模板 | Seedream 5.0 Pro 整图任务 | 图片内必须直接出现的功能文字 | 原生 Card 任务 |
| --- | --- | --- | --- |
| `training-notice` | 学习 → 实践 → 展示的轻量横向关系 | 标题 + 3 个日期/阶段短标签 | 开营说明、培训时间、完整时间轴、鼓励语、CEO 寄语、按钮 |
| `course-schedule` | 日历、课程路径、学习对象的横幅场景 | 标题 + 课程状态/路线短标签 | 时间块、周次列表、预约按钮 |
| `case-showcase` | 问题 → 做法 → 结果的案例关系 | 标题 + 关键阶段/指标短标签 | 背景、KPI、里程碑、成果和引用 |
| `course-recap` | 人物 + 工具界面的工作场景 | 标题 + 能力关键词短标签 | 真实 UI 截图、能力解释和 CTA |

如果一个文案同时命中培训和时间线，默认使用 `training-notice` 的 Seedream 5.0 Pro 整图信息卡；图片直接显示日期、阶段、动作和必要寄语，Card 原生层再提供可编辑事实与真实交互。
